# QA-кейс: ручное тестирование Chrome-расширения Mailshade

Портфельный кейс по мотивам реальной freelance-работы: пользовательское и исследовательское
тестирование расширения Mailshade (блокировка трекинг-пикселей в веб-почте, локальный отчёт,
предупреждения о трекинговых ссылках). Отчёт и таблица находок приняты заказчиком;
данный репозиторий — расширенная документация кейса, оформленная по стандартам QA-документации.

## Паспорт кейса

| Параметр | Значение |
|---|---|
| Продукт | Mailshade, Chrome Web Store (публичная сборка) |
| Тип работ | Ручное пользовательское тестирование + exploratory |
| Роль | Тестировщик, автор документации |
| ОС / браузер | Zorin OS 18.1 Education (Linux) / Chrome 149.0.7827.155 (64-bit) |
| Версия расширения | 1.0.5 (в брифе указана 1.0.3 — расхождение задокументировано, см. Q-1) |
| Почтовый клиент | Gmail, тестовый аккаунт |
| Длительность | ~4–5 часов, включая exploratory-сессии |

## Результаты в цифрах

- **19 находок**: 3 BUG (из них 1 Major в ядровой фиче), 9 UX (1 Major), 3 Cosmetic, 4 Copy/i18n;
- **5 вопросов разработчику** (версионирование, модель данных пикселей, поведение allowlist);
- **15 сценариев «проверено и работает»** (разрешения, перезапуск, Slow 3G, экспорт, темы/языки и др.);
- **Доказательства**: 14+ скриншотов, 6 видео, CSV-экспорт, дамп локаль-каталога.

## Ключевые находки (топ-4)

1. **BUG-1 (Major)** — link warning показывает идентичные URL в полях «Исходный» и «Реальный адрес»:
   unwrap для Customer.io не работает, заявленный обход клик-трекинга не выполняется.
2. **UX-3 (Major)** — инфляция событий: каждое открытие письма логирует полный батч link-событий
   (48 → 74 → 164 при двух уникальных письмах), декупа нет.
3. **BUG-2** — график бакетирует события по UTC-дню, таблица — по локальному: расхождение дат у полуночи.
4. **BUG-3** — визуальная нестабильность инъекций в Gmail (мигание «глаза»/баннера, ghosting контента),
   зафиксирована на видео; на данные не влияет.

## Методы, которыми гордится кейс

- **Локаль-форензика**: анализ `_locales/ru/messages.json` выявил несуществующие контакты,
  несовпадение ключа и сообщения, смешанный тон «ты/вы» и скрытые фичи (контекстное меню).
- **CSV-форензика**: сопоставление UTC-таймстампов экспорта, локальной таблицы и оси графика
  доказало баг бакетирования (BUG-2) и природу «дублей» (UX-3).
- **Видео-фиксация артефактов**: ghosting контента и мигание инъекций (BUG-3).
- **Ручная декодировка base64-обёртки** трекера как доказательство извлекаемости реального адреса (BUG-1).

## Конфиденциальность

Личные письма, адреса и приватные данные в репозитории отсутствуют. Все использованные
отправители — маркетинговые рассылки тестового аккаунта; при необходимости домены
псевдонимизированы. Токены, ключи и пароли не собирались.
