# 08 · Окружение и инструменты

## Окружение
| Параметр | Значение | Примечание |
|---|---|---|
| ОС | Zorin OS 18.1 Education | Linux, Ubuntu-based |
| Браузер | Chrome 149.0.7827.155 (64-bit) | `chrome://version` |
| Расширение | Mailshade 1.0.5 | «О программе»; бриф — 1.0.3 (Q-1) |
| Почта | Gmail (тестовый аккаунт) | личная/рабочая не использовались |
| TZ | системная ведёт себя как UTC+2 при ожидании МСК | зафиксировано как особенность окружения |

## Инструменты
- Chrome DevTools: Network (Slow 3G), Console (фильтр Errors).
- `chrome://extensions`, `chrome://version` — разрешения, версии.
- Дамп `_locales/ru/messages.json` через DevTools — статический анализ строк.
- Анализ CSV в таблице/тексте — сверка таймстампов и батчей.
- Ручная декодировка base64 из обёрток трекера.
- Запись экрана и скриншоты; Python (openpyxl, python-docx) — генераторы отчётов (tools/).

## Техники
Checklist-based по брифу; exploratory с чартерами; negative/edge (пустые состояния, невалидный ввод,
снятие/возврат фильтров); data consistency между поверхностями; i18n/тема-ревью; A/B (выкл/вкл расширения).
