# 04 · UX / Cosmetic / Copy находки

## UX

**UX-1 · Minor · Фильтр «Клиенты» дашборда не отражает реальные разрешения.**
Где: дашборд ↔ настройки ↔ онбординг. Что не так: при одном подключённом Gmail в фильтре взведены все 6 клиентов.
Почему проблема: пользователь сознательно выдавал доступ одному сайту — интерфейс создаёт ощущение «доступно всё».
Как должно быть: активен только подключённый клиент; остальные сняты или помечены (в локали даже есть строка
«Нужен доступ на этом устройстве», но она не используется). Доказательства: `onboarding_clients.png`,
`dashboard_filters.png`, `settings_clients.png`.

**UX-2 · Minor · Pro-триал активируется автоматически, без opt-out.**
Где: онбординг, шаг 3. Что не так: экран констатирует «Pro-триал на 14 дней активирован», кнопок пропуска нет.
Почему проблема: согласие на триал (и связанные с ним условия) принимается молча.
Как должно быть: явный выбор. Доказательства: `onboarding_trial.png`.

**UX-3 · Major · События умножаются при каждом открытии письма (нет декупа).**
Где: отчёт, KPI. Что не так: каждое открытие логирует полный батч link-событий: 48 → 74 → 164 при двух
уникальных письмах. Почему проблема: цифры — витрина продукта; инфляция вводит в заблуждение о масштабе слежки.
Как должно быть: дедуп по (письмо, ссылка) или метрика «уникальных ссылок».
Доказательства: `dashboard_74.png`, `export.csv`, `video_flicker_artifact.mp4`.

**UX-4 · Minor · «Недавняя активность» ограничена 50 строками без пагинации.**
Как должно быть: пагинация или «показать ещё»; сейчас сверх 50 — только CSV. Доказательства: `activity_table.png`.

**UX-5 · Minor · В таблицах нет сортировки** (время/трекеры/клиент). Доказательства: `activity_table.png`.

**UX-6 · Minor · Контекстное меню Mailshade доступно только внутри открытого письма.**
ПКМ по строке во входящих не даёт пунктов «Mailshade: …» — естественное место действия отсутствует,
фича необнаруживаема (найдена через локаль-каталог). Доказательства: `context_menu.png`.

**UX-7 · Minor · Неочевидны кнопки «Открыть напрямую» / «Открыть исходную».**
Пользователю не понятно, какой переход безопасен; на фоне BUG-1 выбор вслепую. Доказательства: `warning_same_urls.png`.

**UX-8 · Minor · Приватный текст онбординга малочитаем.**
Мелкий серый низкоконтрастный блок с жаргоном (accessibility label, host grants, Chrome Sync).
Как должно быть: 3–4 буллета сути, детали под кат. Доказательства: `onboarding_clients.png`.

**UX-9 · Minor · Одни метрики названы по-разному в popup и дашборде.**
Popup: «Обнаружено трекеров / Отправителей с трекерами / Найдено трекинговых ссылок»;
дашборд: «События трекеров / Уникальных отправителей / Ссылочных трекеров». Доказательства: `popup.png`, `dashboard.png`.
